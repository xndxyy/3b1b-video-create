1957年。

## 第二段：生物灵感 (0:30-1:10)
【动画】左侧缓缓浮现一个简化的生物神经元：椭圆细胞体，左边伸出一团树突（蓝色分叉），右边伸出一条轴突（绿色），末端是突触。
旁白同步：箭头指向"树突"和"突触"。
文字浮现："电信号 · 0/1 · 流动"。
然后右侧浮现一个人工神经元图，与生物图形成对照。

要理解感知机，我们先看一样东西——你大脑里的一颗神经元。

一颗神经元长这样。左边这一团像树枝一样的东西，叫树突。它们负责接收来自其他神经元的信号。
信号在细胞体里汇合、叠加。
如果叠加之后的强度，超过了一个临界值，神经元就会"啪"一下，沿着右边这条轴突，发出一股新的电信号出去。

要么不发射，要么全功率发射。没有中间状态。

1957年，一个叫 Frank Rosenblatt 的心理学家盯着这个生物学事实，灵感来了：
"我能不能用数学，把这件事模仿出来？"

于是就有了感知机。

## 第三段：感知机结构 (1:10-2:00)
【动画】舞台清空。一个人工神经元从中心浮现。两个输入节点 x1、x2 出现在左侧。
连接线从输入延伸到中心神经元，权重 w1、w2 数字浮现在连线上。
中心神经元内显示 Σ。
右侧出现比较器 "> θ ?"。
右边分叉箭头：上→"1 (激活)"，下→"0 (静默)"。
信号"0"和"1"沿着连线流动的脉冲动画。

好，现在我们把生物神经元翻译成数学。

一个感知机，结构就这么简单。左边两个输入，x1、x2。
每个输入连到中间这个圆，圆里做一件事：把进来的信号，乘以各自的权重，再加在一起。
w1 乘 x1，加上 w2 乘 x2。

如果这个总和超过一个阈值 θ，圆就会输出 1。这叫"激活"。
没超过，就输出 0。这叫"静默"。

就这么四步。接收、乘、加、比较。

注意，权重可不是随便给的。权重越大的输入，对最终结果的影响就越大。
你可以把权重想成"这条信号线有多粗"。粗线通过的信号多，细线通过的少。
所以，权重的本质，就是一个开关旋钮。拧大一点，这个输入就更有发言权。

## 第四段：偏置项 (2:00-2:40)
【动画】公式 w1·x1 + w2·x2 > θ 浮现，然后下方慢慢变化：
θ 飘到左边，变成 -b。比较器 "> θ" 变成 "> 0"。
新公式：w1·x1 + w2·x2 + b > 0 → 1。
旁白可视化：x1、x2 越轴平移到 x1' = x1 + b/w1。
强调"偏置让决策边界可以平移"。

但你看原版公式里那个阈值 θ，写起来有点别扭。输入是 x，权重是 w，唯独这个阈值是单独拎出来的。
数学家会嫌它丑。

所以我们做一个小手术。把 θ 挪到等号左边，再取个相反数，改名叫 b。
b 就是偏置。

这样公式就优雅多了：w1·x1 + w2·x2 + b，大于 0 就激活，小于等于 0 就静默。

你会问，偏置 b 到底有什么用？

你看啊，没有偏置的时候，感知机的决策边界必须经过原点。
但现实里大部分问题，比如"收入多少算高"、"温度多少算发烧"，它的分界线根本不过原点。

偏置 b，就是给决策边界一个平移的自由度。
它让感知机可以从原点出发，往任何方向滑，停在任何地方。

这是感知机里最容易被新手忽略，但几何意义最深的一个参数。

## 第五段：简单逻辑门 (2:40-3:40)
【动画】左侧出现感知机图，右侧出现真值表。
第一组参数：(0.5, 0.5, 0.7) → 标题"AND 与门"
真值表四行依次出现，只有 (1,1) 行高亮金色。
然后参数变成 (-0.5, -0.5, 0.7) → 标题"NAND 与非门"
真值表反向，3行高亮。
然后参数变成 (0.5, 0.5, -0.2) → 标题"OR 或门"
真值表3行高亮。
最后文字浮现："同一个结构 · 三个身份"

现在让我们用感知机做点事。

最简单的逻辑电路：与门。两个输入都是 1 才输出 1。
我告诉你一组参数：w1 = 0.5，w2 = 0.5，b = -0.7。

我们手算一遍。
(0,0)：0.5×0 + 0.5×0 - 0.7 = -0.7，不激活，输出 0。
(0,1)：0.5×0 + 0.5×1 - 0.7 = -0.2，不激活，输出 0。
(1,0)：同理，-0.2，输出 0。
(1,1)：0.5 + 0.5 - 0.7 = 0.3，激活，输出 1。

完美。这就是与门。

我把偏置从 -0.7 改成 0.7。
(0,0)：0 - 0 + 0.7 = 0.7，激活！输出 1。
(0,1)：0 + 0.5 + 0.7 = 1.2，激活。
其他都激活。

这就是与非门。NAND。Not AND。

我再把偏置改成 -0.2。
(0,0)：-0.2，不激活，输出 0。
其他都超过 0，激活。

这就是或门。OR。

看清楚了吗？
感知机的结构一个像素都没动。
我们只是拧了几个旋钮，改了几个数字。
它就从一个"严格"的角色，变成了"宽松"的角色，又变成了"只挑一种情况"的角色。

权重和偏置，就是这个演员戴的三张面具。

## 第六段：几何视角 (3:40-4:40)
【动画】坐标系出现。x1 横轴，x2 纵轴。
四个点(0,0)(0,1)(1,0)(1,1)出现。○和△标记。
一条直线 w1·x1 + w2·x2 + b = 0 慢慢浮现，平移、旋转。
AND门：直线穿过 (0,1)(1,0) 之间，正确分割。
OR门：直线在原点附近，4个点被分割。
然后两条直线叠加在动画里对比。

但数学家更喜欢换一种视角看感知机。

把 x1 当横轴，x2 当纵轴，画一个二维坐标系。
把 (0,0)、(0,1)、(1,0)、(1,1) 这四种输入，画成四个点。
○ 表示输出 0，△ 表示输出 1。

感知机的公式 w1·x1 + w2·x2 + b = 0，在几何上是什么？
一条直线。

感知机做的事情，本质上是用一条直线，把平面切成两半。
直线一边的点全部判为 1，另一边的点全部判为 0。

这就是为什么感知机能解决与门：四个点里，○ 和 △ 摆在对角的位置上，恰好能用一条直线分开。
或门也一样。

但注意，这条直线只能做"线性"分割。
它没有弯的能力。
这就是感知机能力的边界——一个线性分类器。

记住这句话。我们后面要考的。

## 第七段：XOR 困境 (4:40-6:00)
【动画】坐标系刷新。XOR真值表浮现。
四个点重新布局：(0,0)和(1,1)是○，(0,1)和(1,0)是△。
尝试画第一条直线→失败。
尝试画第二条、第三条→都失败。
直线疯狂旋转、平移，始终无法把○和△分到两侧。
最后整个画面闪红叉。
"1969 · Minsky & Papert · Perceptrons" 文字淡入。
"AI 寒冬" 文字浮现，背景渐暗。

好，期末考试来了。

异或门，XOR。
两个输入相同时输出 0，不同时输出 1。
就这一个电路，难住了整个学界十年。

我先在坐标系上把它的点画出来。
(0,0) 输出 0。
(0,1) 输出 1。
(1,0) 输出 1。
(1,1) 输出 0。

○ 和 △ 摆成了一个 X 形。

现在，回忆刚才我们说的——感知机是一条直线。

你试试。用一条直线，把这四个点切开。○ 一边，△ 一边。

你试。我等你。

……

做不到。

不是参数没调对。是数学上根本不可能。
你要把对角的两个○ 切到一边，把对角的两个△ 切到另一边。一条直线做不了这件事。

这就是 1969 年 Minsky 和 Papert 在他们那本著名的书《Perceptrons》里严格证明的结论：
单层感知机，无法表示异或门。

这本书一出版，资助停了，研究者撤了。
神经网络的研究，直接掉进了"AI 寒冬"。
整整十几年，无人问津。

## 第八段：多层突破 (6:00-7:30)
【动画】舞台切回感知机图，但这次出现三个圆，分两层排列。
左层：x1, x2。
中层：NAND 圆（粉色）、OR 圆（紫色）。
右层：AND 圆（金色）。
连接线从左到中，从中到右。
真值表在右侧出现，逐行验证：
(0,0)：NAND=1, OR=0, AND(1,0)=0 ✓
(0,1)：NAND=1, OR=1, AND(1,1)=1 ✓
(1,0)：NAND=1, OR=1, AND(1,1)=1 ✓
(1,1)：NAND=0, OR=1, AND(0,1)=0 ✓
每行末尾打绿勾。

但故事没完。

1980 年代，有人盯着这个问题想了一个晚上。第二天早上，他说：单层做不到，那就叠一层啊。

你看。我们刚才其实已经造出了三个感知机：与门、与非门、或门。
我们能不能把它们拼起来？

具体怎么拼？我们要做一个异或门，让它需要"两个输入不一样"才输出 1。

思路是这样的。先用与非门和或门，把输入"加工"一下。
再把加工后的两个信号送进与门。

我们走一遍。
输入 (0,0)：与非门算出 1，或门算出 0，1 和 0 送进与门，输出 0。✓
输入 (0,1)：与非门算出 1，或门算出 1，1 和 1 送进与门，输出 1。✓
输入 (1,0)：与非门算出 1，或门算出 1，1 和 1 送进与门，输出 1。✓
输入 (1,1)：与非门算出 0，或门算出 1，0 和 1 送进与门，输出 0。✓

四种情况，全对。

单层做不到的事，加一层，就搞定了。

这就是多层感知机。Multi-Layer Perceptron。
也是今天所有神经网络的雏形。

## 第九段：流水线比喻 (7:30-8:20)
【动画】网络图保留，但视觉重塑：
第一层 = 一组"工人"，第二层 = 另一组"工人"，零件在传送带上移动。
每个工人对零件做一次加工（一次感知机计算）。
文字浮现："加工 → 重新组合 → 加工"。
最后画面定格在 XOR 网络上，注释："层与层之间，特征被重新表达"。

这个结构的妙处，值得再讲一遍。

你可以把多层感知机想象成一条流水线。
第一层的工人拿到原材料——也就是输入 x1、x2。
每个工人做一次感知机运算，把结果传给下一层。
下一层的工人再加工一次，再传给再下一层。

每一层的工作都不是重新发明轮子，而是把上一层的结果"重新表达"一下。
第一层把 x1、x2 表达成了 s1、s2——这两个信号不再只是原始输入，而是某种"组合特征"。
第二层在 s1、s2 的基础上再做一次判断，得到最终输出。

这就是深度学习里"深度"两个字的来历。
不是网络的宽度，是层数。
层数越多，能表达的"组合特征"就越复杂。
从边，到形状，到部件，到物体。
一层一层往上抽象。

这个思路，一旦被点破，就再也不是秘密了。
但当时的人花了十几年才想通。

## 第十段：从 NAND 到计算机 (8:20-9:40)
【动画】一个简单的 NAND 门图形在屏幕中央。
然后从 NAND 引出箭头到右侧，箭头另一端浮现"NOT 门"图形。
再从 NOT 拉箭头到"AND 门"。
从 AND 拉箭头到"半加器"。
半加器展开：两个与门、一个或门、一个与非门。
从半加器到"全加器"，到"加法器阵列"，到"ALU"，到"CPU"，到"计算机"。
每一级在展开时都伴随着微小动画，最终聚合成一台现代计算机的轮廓。

现在我们再往前走一步，看一个更炸裂的事实。

你还记得与非门 NAND 吗？那个我们用感知机实现的、最简单的逻辑门。
理论上，你只需要把 NAND 堆起来，就能造出一台完整的计算机。

怎么堆？
NAND 加上几个组合，变成 NOT 门。
NOT 加上 NAND 组合，变成 AND 门、OR 门。
把 AND 和 XOR 拼起来，变成半加器。
两个半加器拼起来，变成全加器。
把全加器排成一排，变成 N 位加法器。
加法器加上选择器、寄存器、控制单元，变成 ALU。
ALU 加上指令解码、内存访问，变成 CPU。
CPU 加上内存、输入输出设备——

就是一台计算机。

这个链条听起来很神奇，但每一级都是确定的工程实现。
有一本经典的书《计算机系统要素：从零开始构建现代计算机》，就是带读者用 NAND 一块一块搭出一台能玩俄罗斯方块的计算机。
而 NAND 本身，可以用感知机实现。

也就是说：感知机 → 多层 → 任意逻辑 → 计算机。

这是不是让你对"一个简单的数学公式"这件事，多了一点敬畏？

## 第十一段：通用逼近定理 (9:40-10:30)
【动画】一个简化的 2 层感知机浮现在屏幕中央。
公式浮现："2层感知机 + 非线性激活函数 → 任意函数"。
然后公式下方出现函数图：sin(x)、阶梯函数、复杂曲线都被一个多层小网络逼近的示意。
文字浮现："理论上 2 层 · 工程上需要更深的网络"。
画面上网络加深，从 2 层到 3 层到 5 层，颜色变深。

数学家还给了我们一个更猛的结果。

有一个定理叫"通用逼近定理"。
它说：只要你有 2 层感知机，激活函数是非线性的（这我们下一章会讲），那它就可以逼近任意连续函数，误差想多小有多小。

任意函数。
sin(x)、抛物线、阶梯、甚至股票曲线。都行。

但"理论可行"和"工程上跑得起来"是两回事。
实际中，要逼近复杂函数，2 层往往神经元不够用。
你得加更多层、更多神经元、更多连接。
这就把"层数"和"宽度"变成了我们能调的两个旋钮。

你调的层数越多、每层越宽，网络的表达能力就越强。
但代价是：参数变多，训练变难，需要的数据变多，需要的算力也变多。

整个深度学习的故事，本质上就是：怎么在表达能力和训练难度之间，找到那个甜点。

这就是深度学习最底层的故事。
